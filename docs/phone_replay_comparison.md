# 手机视频回放：曝光与识别表现补充测试

日期：2026-11-06。工业相机：MV-CS016-10UC，序列号 DA4302122。

## 素材来源与条件

真实机器人装甲板供电不足后，使用手机播放已有机器人视频，工业相机拍摄手机屏幕，并运行相同的 C++ YOLO 识别流程。以下内容均属于手机回放补充测试，必须与直接拍摄真实机器人的曝光/增益数据分开。屏幕亮度、刷新、播放内容和相机对焦等均可能影响结果。

按本轮操作安排，较亮组设置曝光 10000 μs、增益 6 dB；低曝光组设置曝光 500 μs、增益 6 dB。这两次对应的 run_1793966137276954_1.log 与 run_1793966255245354_1.log 在整理时均为 0 字节，参数实际读回和退出清理证据尚待补充；不将其作为有效运行日志引用。

## 如实描述结果

较亮截图中装甲板被识别为 B3，置信度 0.90；低曝光截图整体明显变暗，但仍显示 B3 检测框，置信度 0.47。因此本组证据支持“画面变暗、截图时刻置信度下降”，不支持“完全漏检”“识别失败”或整段检测稳定性下降的结论。较亮组部分区域也明显偏亮，不代表全图曝光都理想。

随后已补充 [低曝光下该帧未检出的案例](phone_replay_no_detection.md)，截图顶部显示 Detections: 0。该次运行已正常结束，日志核对曝光读回 500 μs、增益读回 5.9953 dB，3518 帧借出/归还一致且清理完整。此前两张仍有框的截图保留原始解释，不改写为漏检。正式真实装甲板对照仍需设备恢复供电后补拍；手机回放能否满足最终演示要求需由老师确认。
